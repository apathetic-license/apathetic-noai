# Draft v99

This document represents a hypothetical future version of the Apathetic
No-AI Use Rider in which all restrictions have been removed. It is provided
for reference only and **is not intended for adoption**. Projects should
continue to use the latest official version, currently Version 1 or later.

No restrictions apply under this draft. It illustrates a potential outcome
if the Apathetic License Collective votes to remove the AI-use limitations.
